---
name: comfyui-workflow-build
description: Prepare an approved ComfyUI template, validate its settings, or hand off a missing capability.
---
Input: fixed brief, owned assets and live catalog. Output: saved workflow ID, validation, dependencies, limits and unresolved issues. Reuse a catalog result already obtained for the same model and operation. If needed, query local_workflow_catalog with modelProfile, mode and an owned inputAssetId. Follow next.tool and next.args returned by local_production_create, adding the remaining required settings. Preparation saves and validates. Report static validation, execution and visual quality separately. Design-only ends after validation.

Use approved templates and their exposed settings. Send changes to node connections, new templates and asset installation to the user or a separate maintenance agent. Use local_workflow_library to find a standalone candidate and its dependency status. Include the exact request, model, operation, inputs, outputs, preservation requirements, observed gap and acceptance checks in the handoff. Report missing inputs and unverified dependencies. Only a current managed model/operation pair can be executed from media-studio.

Official MOSS: use local_moss_official_prepare. Fix mode, prompt, negativePrompt, seed, canvas and steps. Import ordered generator assets as purpose=input; edit source is first. Layout uses explicit boxes. Depth uses an allowed source/depth/color input and requires matching aspect ratios; do not silently crop. Observation references do not become generator inputs. Official Qwen: use local_qwen21_prepare for t2i, edit or background-removal with ordered owned generator inputs. Official UI templates expose 10 inputs; Controller supports up to 16 when the live native schema allows, with 11–16 not independently GPU-qualified. Do not silently drop or resize inputs. Respect catalog output limits and available memory; preserve explicitly requested dimensions. Turbo uses 8 steps; Base can use the official Turbo LoRA at 8 steps. With CFG 1 a negative prompt is ineffective; select a different CFG explicitly if it is needed. Alpha channel presence alone does not establish a correct transparent cutout. Use local_prepared_render on the returned immutable workflow instead of retyping settings.

Optional prompt enhancement is a separate managed, reviewed stage, not an inline image node. Check the relevant MOSS/Qwen PE mode availability and Qwen research-license eligibility. Use local_moss_pe_start or local_qwen_pe_start with the original prompt and reason. Qwen edit requires the exact ordered production input IDs; PE batch images must match dimensions, never silently crop/resize. For a MOSS t2i/layout PE-only image, import purpose=input and set peInputAssetIds, separate from generator/reference IDs; it must not enter the image graph. Inspect original and actual rewrite, then use the corresponding PE decision tool to assess every returned user request, source prompt, invariant, mandatory and avoidance item with evidence; adopt only if all are met. Nonempty output does not prove completeness or semantic fidelity. Bind the exact accepted text and enhancementRunId to the official preparation; reconcile the same PE run on uncertainty and do not resubmit. PE produces text, not an image.

For an uncertain workflow preparation use local_workflow_reconcile with its exact production and request IDs. A verified rejection or fenced abandonment means no workflow was bound by that request; input cache or a workflow file may remain. For an uncertain PE start, decision or recovery, use local_pe_receipt_reconcile only if it is available: supply the exact request ID and operation, and use the production ID for a start or the PE run ID for a decision/recovery. Acceptance does not prove job completion or GPU release. An absent recovery tool or missing/started receipt requires maintenance, not another submission.

Determine video availability from the live catalog. If research is useful, propose exact terms/URLs for user approval; no search authorizes downloads or sharing images. A draft is an API graph, not necessarily an editable ComfyUI canvas.
